虚拟试衣给你一张图。
它给不了你的眼睛。

把衣服贴到模特身上，看一眼，关掉。这类工具解决的是「这套穿在我身上大概什么样」，看完还是不知道它为什么好看、换成别的行不行。

外在换了个方向：它只用你衣橱里已经有的东西，挑出一套，然后告诉你每件在配色里扮演什么角色——谁是主色，谁是底色，点缀落在哪，哪里会有风险。

看懂一次搭配的道理，下次自己就能判断。这是它能陪你久一点的原因。

一件衣服，从照片到一套搭配

  1. 拍一张照片

    对着单品拍一张，照片在本机压到 1600px 再上传。登录后自动识别，未登录也可以手动填写。

  2. 确认属性

    识别会给出品类、颜色和版型的建议，但保存前由你逐项确认。识别结果只是建议，不是结论。

  3. 挑一套出来

    按上装、下装、外套、鞋履、饰品各挑一件，凑成一套。它只从你已有的衣服里选，不推销任何新东西。

  4. 看懂为什么

    给出颜色角色的解释与需要注意的地方，并留下「下一课」：这次没弄懂的点，接着练。

功能

衣橱

拍照录入
上传后自动识别品类、颜色与版型，确认后入库。未登录时由你手动填写名称、品类和版型。
按品类管理
上装、下装、外套、鞋履、饰品分开看，先把拥有的东西看清楚，再谈买什么。

搭配

从衣橱里挑一套
按品类各选一件组成搭配，并给出风格评分与「为什么成立」的三条理由。
解释颜色角色
说清哪件是主色、哪件是底色、点缀落在哪，以及这一套在比例和温度上要注意什么。

训练与预览

每天一课
一节课只练一个判断：给出两套配色，先自己选更耐看的那套，再看解释。
2D 比例预览
按你的身高与肩腰比例，在本机画出一个轮廓提示。它只是比例示意，不代表真实尺码或合体结果。

另有深色模式、登录后自动识别、未登录可用的本地衣橱与训练。

身材数据不出这台手机。

这不是隐私政策里的一句承诺，而是可以从权限与代码上核对的做法。

搭配由服务端生成，需要联网；但身材数据只保存在本机，不随搭配请求上传。上传的只有你选择用于识别的单品照片。

  • 模型密钥 只在服务端

    APK 内没有任何模型供应商的 Key，也不允许用户填写 Key。识别请求由服务端代理。

  • 身材数据 仅本机

    身高、肩宽、腰围只用于本地的比例提示，当前版本不会发送到服务器。

  • 登录凭证 Keystore 加密

    登录 token 用 Android Keystore 的 AES-GCM 加密后保存，不参与系统备份。

  • 注销账号 一并清除

    注销会删除服务端的账号与识别记录，并清空本机的衣橱数据。
